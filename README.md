# 夜萤 / Firefly

手柄优先的 Unity 3D 夜间飞行体验。Unity 工程位于 `Flyfly/`，使用 Unity **6000.0.66f2**、URP **17.0.4**、Input System **1.17.0**。

## 开始游玩

1. 在 Unity Hub 中打开 `Flyfly` 工程。
2. 打开 `Assets/Firefly/Scenes/NightMeadow.unity`，切到 Game 视图并按 Play。
3. 连接系统识别的手柄。在三处虫群聚集的草地附近点亮荧光，其他萤火虫会聚集回应，一同照出附近的草木。

| 动作 | 手柄 | 键盘后备 |
| --- | --- | --- |
| 水平飞行 | 左摇杆，幅度控制速度 | WASD / 方向键 |
| 上升 / 下降 | RT / R2、LT / L2，扳机幅度控制速度 | Space、Ctrl |
| 转动视角 | 右摇杆 | 按住鼠标右键拖动 |
| 开关荧光 | A / ×（南侧面键） | F |
| 加速滑行 | RB / R1 | Shift |
| 暂停 / 继续 | Menu / Options | Esc |

玩家可以在草地上空自由升降，水平移动方向随视角变化。水平与垂直同时输入会统一限制速度；地面、障碍与飞行高度边界会限制移动。右摇杆可以环绕转动镜头，俯仰角受限以避免倒转。默认相机距离约 18 米，萤火虫只占画面很小的部分；身体悬停、倾斜和振翅独立于相机目标。输入包含径向死区、失焦暂停、断连清零，以及短促的光开关振动反馈。

## 首版内容

- 程序生成的草地、蕨类、林缘树木、湿润地面、石块与倒木。
- 极弱的冷色月光和环境光，草地与森林平时难以辨认；贴地雾同样依靠真实光源受光。
- 单只玩家的荧光只照亮身边的一小块。虫群共同发光时，多盏真实点光源叠加，显出局部草地、树木与薄雾。场景始终保留大片暗处。
- 112 只合批环境萤火虫，独立漂移、闪烁，三个局部虫群会回应玩家，每次共同发光约 10 秒。附近最多 24 盏无阴影点光源，使用 PC Forward+ 渲染；远处保留光点，限制实时照明开销。
- 远处低细节林木与外围地面覆盖环绕视角。
- 简化萤火虫模型、动态翅膀、设备提示、暂停界面，以及原创程序合成的风声、虫鸣和振翅。

美术和声音目前使用程序生成的样板资源；后续可替换为更精细的植物模型、虫体模型和实地录音。真实手柄型号兼容性、振动手感和目标硬件帧率仍需实机确认。

## 编辑与验证

- `Firefly > Build Night Meadow`：从固定随机种子重建场景，须先保存当前场景，已有场景不会被无提示覆盖。生成的网格、材质和 Volume Profile 保存到 `Assets/Firefly/Generated/`。
- `Firefly > Validate Gamepad Flight`：通过 Input System 的临时模拟手柄验证实际 Play Mode 行为；结果写入 `Library/FireflyValidation.json`。不会代替真实手柄测试。
- 主要组件在 `Assets/Firefly/Scripts/`；环境着色器在 `Assets/Firefly/Shaders/`；编辑器构建、验证入口在 `Assets/Firefly/Editor/`。
- `Artifacts/NightMeadow.png` 为实际运行画面的预览（生成后可查看）。

## 已验证的当前版本

在 Unity 6000.0.66f2 中运行模拟手柄与键盘，35 项 Play Mode 检查全部通过，运行错误 0：升降、键盘升降、三维限速、高度边界、上下表面碰撞、右摇杆视角、视角改变后的移动方向、远景构图，以及原有的荧光、暂停、加速、断连、失焦与虫群回应。测试结束时回收模拟设备，并恢复输入系统、音频和编辑器设置。

实测玩家身体高度约占画面 1.89%。单只玩家点光源强度为 0.3、范围 1.65；第一处虫群回应时，13 盏真实点光源共同照明。同一机位的回应截图平均亮度约为熄灯基线的 23.75 倍，可见草叶和石块，而其余森林几乎全黑。

最后视觉检查记录 88 个 Renderer、535,822 个三角形，缺失材质 0、Shader 编译错误 0。植被按区域合并，草叶关闭投影，环境光点合为单个动态网格；这是结构与运行检查，尚未对指定目标显卡承诺帧率。

实际虫群发光与熄灯截图位于 `Artifacts/`。当前截图来自 Unity 主相机的 URP 离屏渲染，1920×1080，包含真实后处理，不包含覆盖式界面。验证结果也保存在该目录，便于脱离本机 `Library` 查阅。模型、植被与声音均为可替换的首版资源，不代表最终写实美术品质。

`SampleScene` 模板保留，Build Settings 的启动场景设置为 `NightMeadow`。没有第三方下载资源或付费插件依赖。
